# DataSolution360

📊 Sales Performance Dashboard (Excel)

An interactive Excel dashboard that turns raw customer transaction data into a clear, filterable view of sales performance. Pick a month and a region from the dropdowns, and every KPI and chart updates instantly.

✨ Features
Dynamic filters: dropdown selectors for Month and Region drive the whole dashboard.
KPI cards that recalculate with the selected filters:
1)Total Revenue
2)Transaction Count
3)Total Quantity
4)Average Unit Price
5)Premium Transactions
6)Premium Revenue
Revenue by Category: Stationery, Electronics, Accessories, Furniture.
Revenue by Customer Type: Premium vs. Regular.
Monthly Revenue Trend: a line chart showing how revenue moves across the year.
Clean, dashboard-style layout with colour-coded headers and a dark trend panel.

🛠️ Tools & Techniques
Microsoft Excel
Excel Tables and structured references
Data Validation (dropdown filters)
Formulas for dynamic aggregation (e.g. SUMIFS, COUNTIFS, AVERAGEIFS)
Charts: column, bar, and line
Conditional use of helper columns (MONTH()) for time-based filtering
Dashboard layout and formatting

🚀 How to Use
Download or clone this repository.
Open CustomerDataClass3H3.xlsx in Microsoft Excel.
Go to the Dashboard sheet.
Use the Month and Region dropdowns to filter the data.
Watch the KPIs and charts update.

🚀What the Dashboard Answers
Which month and region generated the most revenue?
Which product categories drive sales?
How much revenue comes from Premium customers versus Regular customers?
How does revenue trend across months?
